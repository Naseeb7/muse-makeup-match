# Muse — Makeup Match

A modern makeup combination explorer that matches makeup elements to skin type, undertone, occasion, and finish using a transparent frontend scoring engine.

## MVP

- Next.js App Router + TypeScript
- Tailwind CSS
- Frontend-only dummy catalog
- Explainable recommendation scoring
- Responsive editorial beauty UI

The recommendation catalog is intentionally local for the MVP so the matching logic can later be replaced by an API or product database without changing the UI contract.
